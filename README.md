# Rocketlaunchet

Build an actual playable, immersive 3D space flight arcade game that fills the browser viewport. Use the attached rocket image only as visual reference. Create a realistic 3D spacecraft faithfully preserving the compact retro rocket silhouette and distinctive details: pointed red nose, warm ivory/white body, prominent circular blue front window with dark metallic rim, red side fins plus a center fin, and bright exhaust. Do not copy NASA or SpaceX designs. Design an atmospheric deep-space experience with a starfield, nebulae/planets, cinematic lighting, responsive camera, convincing ship movement and thrust. It must be an actual game, not a static mockup: keyboard controls (WASD or arrows to steer, Space to boost/fire if appropriate), mouse/touch support, obstacles or targets, collision feedback, score/distance, pause/restart, and a clear start screen/how-to-play overlay. Keep HUD polished and unobtrusive; ensure full viewport responsive behavior and make gameplay immediately understandable. Implement the 3D scene with robust performance/fallback behavior. Check that interactions and game loop work in the preview.
